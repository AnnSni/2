# Pink & Purple World

webové stránky vytvořený pomocí HTML a CSS.

## růžová stránka 

Stránka používá růžovou barvu.

Na stránce jsem použila:

- HTML strukturu
- externí CSS
- CSS Grid
- relativní jednotky
- nadpisy h1, h2 a h3
- SEO informace
- hover efekt
- jednoduchý responzivní design

## Soubory

- `index.html` – hlavní stránka
- `style.css` – vzhled stránky
- `README.md` – informace o projektu
